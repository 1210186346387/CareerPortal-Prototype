CareerPortal HTML/CSS Prototype
================================
Files:
- index.html: landing page with student/company entry points
- student-verification.html: student verification screen
- student-profile.html: profile creation screen
- jobs.html: student job search/listings screen
- company-profile.html: company profile creation screen
- post-job.html: company job listing screen
- candidates.html: suitable candidate list screen
- style.css: shared responsive styling

How to run:
1. Extract this ZIP.
2. Keep all files in the same folder.
3. Open index.html in a web browser.
4. Use the links/buttons to move between prototype screens.

Limitations:
This is an HTML/CSS-only visual prototype. Forms and search/filter controls are illustrative;
there is no real verification, login, database storage, file upload, or AI matching logic.
